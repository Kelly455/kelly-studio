 # KELLY.DEV

Portfolio and service site for a freelance web developer. Built with plain HTML, CSS and JavaScript, with no frameworks or libraries.

**Live site:** https://kelly455.github.io/kelly-studio/

## Features
- Looping blurred video hero, with a pause button and a reduced-motion fallback
- Light and dark theme toggle that remembers the visitor's choice
- Frosted-glass interface with solid fallbacks for browsers or users that prefer less transparency
- Expanding service panels (hover on desktop, tap on mobile)
- Contact form with field validation, delivered through Formspree
- Mobile-first layout
